# TimeRunner

Unityで制作した3Dアクションゲームです。  
プレイヤーはステージを進み、障害物を避けながらより早いタイムでのゴールを目指します。

## 制作背景

3Dゲーム制作の経験を積むために、企画・実装・演出まで個人で制作しました。  
TPS視点での操作性や、プレイしやすいゲーム体験を意識して開発しました。

## 使用技術

- Unity
- C#
- URP
- Git / GitHub


## 主な実装内容

- TPS視点キャラクター操作（アセットの内容を一部改良）
- ジャンプ / 移動（アセットの内容を一部改良）
- タイムスロー機能
- スロー中の画面演出（歪み・エフェクト）
- タイトル画面 / リザルト画面
- ステージクリア判定
- UI表示

## 工夫した点

### タイムスロー演出

ゲーム速度を落とすだけでなく、画面エフェクトの追加と画面の色調を青くすることで、  
視覚的にもプレイヤーが能力を使っている感覚を強めました。
また、能力とクリアタイムのバランスを取るために能力使用中もタイマー自体は同じ速さで進むようにしました。


## 操作方法

- WASD : 移動
- Space : ジャンプ
- ジャンプ後にもう一度space : 二段ジャンプ
- Shift : ダッシュ
- E : タイムスロー
- マウス : 視点操作
